# NVIDIA Shader Extensions (nvapi HLSL headers)

HLSL/C++ headers exposing NVIDIA GPU shader extensions (warp shuffle, vote,
ballot, wave match, etc.) for use in shader code and the D3D11/D3D12 drivers.

Upstream: NVIDIA/nvapi, https://github.com/NVIDIA/nvapi
Vendored files: nvHLSLExtns.h, nvHLSLExtnsInternal.h, nvShaderExtnEnums.h
(NV_SHADER_EXTN_VERSION 1), copyright 2019-2024 NVIDIA CORPORATION, MIT license.
