# ImGuiColorTextEdit

Colorizing text editor widget for Dear ImGui, used as the code/script editor
in Dagor tools. Based on the santaclose fork of BalazsJako's original
ImGuiColorTextEdit (adds multicursor, auto-indent and more language
definitions), further modified for Dagor with a Daslang language definition
and folder-view integration. No fixed upstream version is pinned.

Upstream: https://github.com/santaclose/ImGuiColorTextEdit
Original: https://github.com/BalazsJako/ImGuiColorTextEdit
