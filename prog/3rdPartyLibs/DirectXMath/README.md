# DirectXMath

All-inline SIMD C++ linear algebra library for games and graphics apps,
covering vectors, matrices, and collision math (used here for the header-only
math API, with local Gaijin adjustments).

Upstream: Microsoft DirectXMath, https://github.com/microsoft/DirectXMath
(MIT License). Vendored version 3.18 (DIRECTX_MATH_VERSION 318, "dec2022"
release).
