# NRD (NVIDIA Real-time Denoisers)

HLSL shaders for NVIDIA's spatio-temporal denoising library (REBLUR, RELAX,
SIGMA), used to denoise ray traced diffuse/specular/shadow signals.

Upstream: NVIDIA-RTX/NRD, https://github.com/NVIDIA-RTX/NRD
Vendored version: v4.17

License: NVIDIA proprietary SDK license (see file headers), not OSI open source.
