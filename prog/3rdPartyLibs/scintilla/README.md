# Scintilla

Public API headers for Scintilla, the source code editing component used by
blkEditor (ILexer.h, ILoader.h, Scintilla.h, ScintillaCall.h,
ScintillaMessages.h, ScintillaStructures.h, ScintillaTypes.h,
ScintillaWidget.h, Sci_Position.h). Only the headers are vendored; the
Scintilla implementation itself is not included here.

Upstream: Scintilla, https://www.scintilla.org/ (canonical source: Mercurial
repo at https://sourceforge.net/p/scintilla/code/). Vendored version 5.5.8.
