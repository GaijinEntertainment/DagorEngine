# libb64

Fast C routines for base64 encoding and decoding (streaming, state-machine
based). Public domain.

Upstream: libb64 by Chris Venter, originally http://libb64.sourceforge.net/,
community fork at https://github.com/libb64/libb64. Vendored version is not
pinned to a specific release; sources correspond to the original SourceForge
public-domain release.
