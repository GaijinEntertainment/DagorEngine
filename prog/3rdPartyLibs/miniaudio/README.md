# miniaudio

Single-file audio playback and capture library for C/C++.

Upstream: miniaudio, https://github.com/mackron/miniaudio
Vendored version: v0.11.23 (2025-09-11)

`extras/` contains miniaudio's own optional decoder plugins (libopus,
libvorbis wrappers) and its bundled copy of stb_vorbis.c (public domain
Ogg Vorbis decoder by Sean Barrett, https://github.com/nothings/stb),
all taken from the same upstream repo's `extras/` directory.
