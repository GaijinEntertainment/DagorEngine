# ska_hash_map

Fast open-addressing (Robin Hood) and chained hash table implementations by
Malte Skarupke: `flat_hash_map`, `bytell_hash_map`, and `unordered_map`
(sherwood_v10, pointer-stable). Licensed under the Boost Software License 1.0.

Upstream: skarupke/flat_hash_map, https://github.com/skarupke/flat_hash_map
(unversioned repo, vendored from master as of August 2018).

`flat_hash_map2.hpp` is a Dagor-local adaptation of `flat_hash_map.hpp` for
EASTL and is not present upstream.
