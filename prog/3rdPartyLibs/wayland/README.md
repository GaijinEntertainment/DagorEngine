# wayland

Client-side Wayland protocol headers and generated protocol marshalling code,
used to build the Wayland backend of the window/input system on Linux.

Upstream: wayland, https://gitlab.freedesktop.org/wayland/wayland, version 1.22.0
(wayland-client-core.h, wayland-client-protocol.h, wayland-protocol.c, wayland-util.h).

The protocol-specific files (xdg-shell, viewporter, relative-pointer-unstable-v1,
pointer-constraints-unstable-v1) are generated by `wayland-scanner` from XML
definitions in wayland-protocols: https://gitlab.freedesktop.org/wayland/wayland-protocols
(see generate_protocols.sh).
