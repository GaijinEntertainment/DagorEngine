C implementation of a bencode decoder (the format defined by BitTorrent,
see http://wiki.theory.org/BitTorrentSpecification#bencoding).

Public domain code written by Mike Frysinger <vapier@gmail.com>, with
improvements from Gilles Chanteperdrix. No official upstream repository
or version tag exists; this single-file decoder has circulated as a
public-domain snippet across multiple projects (e.g. it is vendored in
Kamailio's rtpengine module and various BitTorrent client sources). No
specific version is tracked here.
