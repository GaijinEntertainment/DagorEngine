This is minizip, a set of small C files for zip/unzip manipulation using
zlib, with Zip64 support. Part of the zlib contrib/minizip project by
Gilles Vollant, with Zip64 extensions by Even Rouault and Mathias Svensson.

Upstream: minizip, https://github.com/madler/zlib (contrib/minizip)
Vendored version: 1.1 (see header comment in unzip.h)
