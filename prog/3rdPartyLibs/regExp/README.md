# regExp

A small C++ regular expression engine (Perl-like syntax, TCHAR-based),
originally written by Walter Bright for Digital Mars. Ported to Dagor
Tech by Nic Tiger.

Upstream: Digital Mars regexp.cpp/regexp.h, from the DMC (Digital Mars
C/C++ Compiler) distribution `\dm\src\core\regexp.cpp`,
https://digitalmars.com/rtl/regexp.html (no public source repository;
distributed as free/unlicensed source with the compiler toolchain,
copyright 2000-2001). No specific vendored version/date is tracked;
present in this tree since 2005.
