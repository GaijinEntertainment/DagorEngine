# arm_asr

Arm Accuracy Super Resolution (Arm ASR), a mobile-optimized temporal
upscaler derived from AMD FidelityFX Super Resolution 2 (FSR2), with a
Vulkan-only backend.

Upstream: Arm ASR Generic Library,
https://github.com/arm/accuracy-super-resolution-generic-library
Vendored version: derived from FSR2 v2.2.2 (FFXM_FSR2_VERSION 2.2.2).
