# breakpad

Google Breakpad, a cross-platform crash-reporting system: client-side
minidump generation (client/) and a minidump processor/stackwalker
(processor/), used here for crash dump collection and analysis.

Upstream: https://github.com/google/breakpad (mirror of
https://chromium.googlesource.com/breakpad/breakpad). Vendored snapshot
from around 2015-01-15 (arm64 stackwalker support present).
