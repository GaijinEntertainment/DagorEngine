ozz-animation: open source C++ skeletal animation library (runtime sampling,
blending, IK, skinning, and offline animation/skeleton building).

Upstream: https://github.com/guillaumeblanc/ozz-animation, MIT licensed.
Vendored version: approximately 0.14.x (has rest_pose naming and move
constructors, predates 0.15 keyframe indexing and 0.16 root motion support).
