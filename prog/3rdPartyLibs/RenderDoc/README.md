# RenderDoc application API header

`renderdoc_app.h` is the public in-application API header for RenderDoc, the
graphics debugger. It is used to load the RenderDoc DLL/so and trigger
captures programmatically from the engine's graphics drivers.

Upstream: RenderDoc, https://github.com/baldurk/renderdoc
(file at https://github.com/baldurk/renderdoc/blob/v1.x/renderdoc/api/app/renderdoc_app.h)
Vendored API version: RENDERDOC_API_1_5_0 (RenderDoc ~1.17+)
