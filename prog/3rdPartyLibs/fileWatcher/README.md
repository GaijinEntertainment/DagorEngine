# fileWatcher

SimpleFileWatcher: a cross-platform (Windows/Linux/OSX) C++ library for
watching directories and receiving notifications of file changes.

Upstream: SimpleFileWatcher by James Wynn,
https://github.com/jameswynn/simplefilewatcher (formerly hosted at
code.google.com/p/simplefilewatcher). No specific release is vendored;
the source predates upstream's tagged releases.
