# cachesim

Insomniac Games' CacheSim: a cache simulator for the AMD Jaguar cache
configuration (used e.g. for PS4/Xbox One era CPU cache behavior analysis).

Upstream: https://github.com/InsomniacGames/ig-cachesim (BSD 2-Clause license).
Vendored from upstream master, no tagged release; snapshot as of 2021-01-12.
