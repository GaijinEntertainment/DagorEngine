# libev

Full-featured, high-performance event loop library by Marc Alexander Lehmann,
loosely modelled after libevent. Also includes event.h/event.c, a libevent
compatibility shim built on top of libev.

Upstream: libev, http://software.schmorp.de/pkg/libev.html (canonical source
is CVS at http://cvs.schmorp.de/libev; git mirror: https://github.com/enki/libev).
Vendored version: 4.20 (EV_VERSION_MAJOR=4, EV_VERSION_MINOR=20).
