# DIA SDK

Headers and import libs (diaguids.lib, x86/amd64) for Microsoft's Debug
Interface Access SDK, used to read symbol/debug info from PDB files.

Upstream: Microsoft DIA SDK, ships as part of Visual Studio
(https://learn.microsoft.com/en-us/visualstudio/debugger/debug-interface-access/debug-interface-access-sdk).
Proprietary, closed-source; no public repo. Headers here correspond to
MIDL compiler version 7.00.0499 (VS2010/2012-era DIA SDK).
