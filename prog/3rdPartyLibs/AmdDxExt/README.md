# AmdDxExt

Header-only interface for AMD's Direct3D 10/11 driver extension API, used to
access vendor extensions such as the Depth Bounds Test on AMD GPUs.

Upstream: AMD common_src_amddxext, https://github.com/GPUOpen-Tools/common_src_amddxext
Vendored: early revision (pre-2016), added to this repo in 2013.
