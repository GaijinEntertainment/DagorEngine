# SMAA

Enhanced Subpixel Morphological Antialiasing (SMAA), a GPU-based
antialiasing shader supporting luma, color and depth edge detection,
distributed as a single HLSL header.

Upstream: iryoku/smaa, https://github.com/iryoku/smaa
Vendored version: master snapshot (no formal upstream release tags exist;
content matches github.com/iryoku/smaa SMAA.hlsl as of the 2013 revision).
