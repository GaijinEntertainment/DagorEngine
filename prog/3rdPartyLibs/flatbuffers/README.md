FlatBuffers: a memory-efficient cross-platform serialization library, with
the `flatc` schema compiler and `flathash` hashing tool built from the same
source tree. The `grpc/` subdirectory contains the FlatBuffers gRPC code
generator, shared with and maintained by the gRPC project.

Upstream: https://github.com/google/flatbuffers, vendored version 1.7.0.
