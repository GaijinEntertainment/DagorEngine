# mit-hrtf-lib

C library giving simple lookup access to the MIT KEMAR Head-Related Transfer
Function (HRTF) compact data set (128 taps, 44100/48000/88200/96000 Hz,
normal and diffuse-field equalized variants) via two functions.

Upstream: MIT HRTF Library by Aristotel Digenis, version 0.1 (2007-05-04).
https://sourceforge.net/projects/mit-hrtf-lib/ (moved to
https://github.com/greekgoddj/mit-hrtf-lib, no longer public; mirrored at
https://github.com/jhonmark/mit-hrtf-lib). License: MIT.
