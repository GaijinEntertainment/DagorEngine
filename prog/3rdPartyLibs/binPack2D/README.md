# binPack2D

2D rectangle bin packing algorithms (Guillotine, MaxRects, Skyline, PowerOfTwo
heuristics), used to pack rectangular regions (e.g. texture atlases) into a
bin with minimal wasted space.

Upstream: juj/RectangleBinPack by Jukka Jylanki, https://github.com/juj/RectangleBinPack
Public domain. Vendored is an older snapshot predating the current upstream
layout (upstream has since dropped PowerOfTwoBinPack and added ShelfBinPack
variants); exact version/commit not recorded.
