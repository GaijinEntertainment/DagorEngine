# 3rdPartyLibs/imgui

Vendored immediate-mode GUI libraries used for engine/tool debug UI.

## Dear ImGui
Upstream: https://github.com/ocornut/imgui
Vendored version: 1.92.6 (see IMGUI_VERSION in imgui.h)
License: MIT (LICENSE_imgui.txt)

Includes ImGui's bundled single-file helper libraries (renamed imstb_*.h,
derived from stb_rect_pack.h, stb_textedit.h, stb_truetype.h) as shipped
with Dear ImGui itself.

## ImPlot
Upstream: https://github.com/epezent/implot
Vendored version: 0.17 (see IMPLOT_VERSION in implot.h)
License: MIT (LICENSE_implot.txt)
