ENet is a thin, reliable UDP networking library providing optional reliable,
in-order delivery of packets, with fragmentation and connection management.

Upstream: ENet, https://github.com/lsalzman/enet (homepage http://enet.bespin.org/).
Vendored version: 1.3.13 (see ENET_VERSION_* in include/enet/enet.h).

This copy has Dagor-specific additions (enet_dagor.c/h, platform headers for
consoles/Switch) on top of the upstream sources.
