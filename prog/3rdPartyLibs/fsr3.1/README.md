# FSR 3.1 ffx-api headers

Public headers for AMD FidelityFX API (ffx-api), the loader interface used to
call into the FidelityFX runtime DLLs (upscaling and frame generation) for
FSR 3.1.

Upstream: AMD FidelityFX SDK, https://github.com/GPUOpen-LibrariesAndSDKs/FidelityFX-SDK
(path `ffx-api/include/ffx_api`), FSR 3.1 release.
