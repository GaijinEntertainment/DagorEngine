# Snapdragon Game Super Resolution

Vendored shader/runtime code for Qualcomm's Snapdragon(TM) Game Super
Resolution (SGSR), a spatial (SGSR1) and temporal (SGSR2) GPU upscaler
optimized for Adreno GPUs, ported to Dagor shaders (dshl) and PostFxRenderer.

Upstream: https://github.com/SnapdragonGameStudios/snapdragon-gsr
(mirror: https://github.com/quic/snapdragon-gsr), BSD-3-Clause license,
vendored around v2.0.0 (2024-10-21).
