# netImguiServer

Server application sources for NetImgui, a library that lets a program using
Dear ImGui forward its UI rendering to a remote PC and receive input back
from it. This is the standalone display/relay server counterpart to the
`netImgui` client library vendored alongside it in `prog/3rdPartyLibs/netImgui`.

Upstream: netImgui by Sammy Fatnassi (Sammyfreg),
https://github.com/sammyfreg/netImgui, vendored at version 1.13.0.
