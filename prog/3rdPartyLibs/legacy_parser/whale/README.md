Whale is an LR parser generator that produces C++ code from `.whl` grammar
files, used together with the Dolphin lexical analyzer generator. It bundles
a small subset of SGI STL hash_map/hash_set headers (hash/) and Vladimir
Prus's extended STL utilities (nstl/) as internal implementation details.

Upstream: Whale by Alexander Okhotin and Vladimir Prus, originally hosted at
http://www.cs.queensu.ca/home/okhotin/whale/ (page no longer available).
Vendored version: 0.2.3 (7 March, 2001).
