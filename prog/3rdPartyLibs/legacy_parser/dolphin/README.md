Dolphin is a lexical analyzer (scanner) generator that produces C++ code
from `.dlp` grammar files, used together with the Whale parser generator.

Upstream: Dolphin by Alexander Okhotin, originally hosted at
http://www.cs.queensu.ca/home/okhotin/whale/ (page no longer available).
Vendored version: 0.2.3 (5 March, 2001).
